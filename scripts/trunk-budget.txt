# Trunk size ratchet — `<repo-relative SKILL.md> <max bytes>`.
#
# A skill's body is loaded per invocation, not per session: every byte here is
# paid each time the skill fires, in every project with the plugin enabled.
#
# THE RULE. A ceiling is a RATCHET: a trunk may shrink freely and may not grow past
# it. A ceiling is the trunk's measured size, never a target, and it comes down
# when the trunk shrinks (check-trunk-budget.py fails a ceiling left above a shrunk
# trunk). It goes up only to pay for a rule that must sit in the trunk, because the
# rule binds at a moment when a pointer followed afterwards is the same as no rule.
# After an extraction, a ceiling is derived from the trunk's
# conditional/unconditional classification and what the cut retained, never from a
# target picked ahead of the measurement. The ceiling follows the obligation, not
# the obligation the ceiling: paying for a rule by deleting a rule, or by moving it
# into a reference file the executor may never open, is the trade this file exists
# to stop. The comment above each ceiling names the rules it pays for, and a change
# to a ceiling changes that comment to match the diff.
#
# Every trunk at or above 10000 B must carry an entry; check-trunk-budget.py
# fails on one that does not, so the ratchet cannot be opted out of by omission.

# honest-gates.
# Its rules are WRITE-TIME disciplines: each has to be in front of whoever is writing
# the test or the check, and a pointer followed after the fact is the same as no
# rule. So a rule sentence never leaves this trunk; only the reason behind it may
# (references/reasons.md). Untiered: these cost a re-run, not an agent. 44 retention
# markers pin the trunk's binding sections; the classification is
# references/extraction-classification.md.

# decide the property, FIRST in its section; the corpus-sweep rule (a
# parsing-contract, marker-vocabulary or classification change does not ship until
# the corpus it reclassifies is inventoried and backfilled or filed); a gate artifact
# the executor authored is disclosed, and one that cannot reach both outcomes is not
# a gate; each guard is reachable from a named test, and a mutation battery proves a
# verdict-producing check; a GREEN names where its evidence executed, and every figure
# in a report is reproducible at a sha; a suite dropped for cost is BLOCKED on that
# suite, and tier-declared narrowing drops only trees the stage neither touched nor
# depends on; the mutant's proof is a prove-claim.py record, and a deviation record is
